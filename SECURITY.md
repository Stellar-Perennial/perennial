# Security

Perennial can sign and send transactions with a key you give it. Treat that key as sensitive.

## Reporting a vulnerability
Do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Contact method to add before launch: <maintainer contact>.

## Scope
Bugs that could leak a secret key, send unintended transactions, bypass the fee ceiling, or bypass dry-run mode.

## Audit status
Perennial has **not** been audited. Use a dedicated low-balance account and test on testnet first.
